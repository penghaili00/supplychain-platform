# 工程基线

## 测试与 CI

- 父级 Maven 构建现在为所有模块统一提供 `spring-boot-starter-test`。
- JaCoCo 会在执行 `mvn verify` 时运行，并生成模块级覆盖率报告。
- GitHub Actions 会在每次 Pull Request 以及推送到 `main`、`master`、`codex/**` 时执行 `mvn -B verify`。

## Flyway

- `supplychain-service-provider` 现在负责通过 Flyway 管理数据库迁移。
- 首个迁移脚本位于 `supplychain-service/supplychain-service-provider/src/main/resources/db/migration/V1__init_schema.sql`。
- Flyway 通过 `nacos/supplychain-service-provider.yml` 启用。
- `baseline-on-migrate=true` 用于兼容已经通过手工方式初始化过的数据库，避免重复执行 `V1`。

## 本地引导

- `docker-compose.yml` 用于启动 MySQL、Redis、Nacos 和 RabbitMQ。
- `scripts/local/bootstrap.ps1` 会启动容器、等待端口就绪，并导入 `nacos/` 目录下的全部 YAML 配置。
- `scripts/local/import-nacos.ps1` 可以单独使用，适合只想刷新 Nacos 配置的场景。

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\local\import-nacos.ps1
```
